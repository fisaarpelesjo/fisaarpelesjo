Sou **Data Analyst** na [NoPing](https://www.noping.com), especializado em arquiteturas analíticas de larga escala para otimização de latência em gaming.

## 🛠️ Stack Principal

**Google BigQuery**
- Modelagem de queries complexas com subconsultas encadeadas (CTEs)
- Funções de janela para análise de sequências e comparação entre registros
- Expansão de séries temporais para métricas diárias e projeções de longo prazo
- Deduplicação e priorização de registros com filtragem avançada
- Parsing e extração de dados de campos JSON
- Normalização e padronização de dados com múltiplos fallbacks
- Consolidação de fontes heterogêneas em estruturas unificadas
- Tratamento seguro de tipos e divisões para evitar erros em produção
- Contagens e agregações condicionais para segmentação de métricas
- Extração de padrões em texto com expressões regulares

**Power BI**
- Modelagem dimensional (star schema)
- DAX avançado com manipulação de contexto de filtro
- Construção de tabelas virtuais para cálculos complexos
- Atualização incremental para grandes volumes de dados
- Segurança em nível de linha (RLS)

**Desenvolvimento**
- JavaScript/TypeScript
- Next.js: renderização no servidor, rotas de API, internacionalização
- React: componentes funcionais, gerenciamento de estado
- APIs REST, feature flags no servidor
